# cards-article-grid

Custom **cards** block. Purpose: article-grid.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Cards: one row per article, 2 cells: [image] | [date p, H3 title wrapped in a link, excerpt p]. Latest 12 articles only, newest first; static grid, no filters, no Show more. Image, date and excerpt are optional; decorative inline SVG icons are dropped.

## Supported variations

No variations.
